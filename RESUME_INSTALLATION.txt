========================================
  2M MARKET - RÉSUMÉ INSTALLATION
========================================

📦 TÂCHE 1 : CRÉER L'INSTALLATEUR
========================================

FICHIER À EXÉCUTER:
  build-exe.ps1

COMMANDE:
  .\build-exe.ps1

RÉSULTAT:
  dist\2M-Market_Setup.exe (installateur Windows)

FICHIERS NÉCESSAIRES (déjà présents):
  ✅ build-exe.ps1
  ✅ pom.xml
  ✅ src/ (code source)
  ✅ database/init_sqlite.sql (copié automatiquement dans ressources)

PRÉREQUIS:
  ✅ Java JDK 17+ (avec jpackage)
  ✅ Maven 3.6+
  ✅ Windows 10/11

========================================
📋 TÂCHE 2 : INSTALLER SUR PC DE CAISSE
========================================

FICHIER À COPIER:
  2M-Market_Setup.exe (UNIQUEMENT ce fichier!)

ÉTAPES:
  1. Copier 2M-Market_Setup.exe sur clé USB
  2. Transférer sur PC de caisse
  3. Double-cliquer pour installer
  4. Lancer l'application (base créée automatiquement)

CE QUI EST INCLUS DANS L'INSTALLATEUR:
  ✅ Application JavaFX complète
  ✅ Java Runtime (JRE) - Aucune installation Java requise!
  ✅ Script SQLite (dans les ressources du JAR)
  ✅ Toutes les dépendances

FICHIERS CRÉÉS AUTOMATIQUEMENT:
  ✅ C:\Program Files\2M-Market\2M-Market.exe
  ✅ C:\Program Files\2M-Market\MarketDB.db (au premier lancement)
  ✅ Raccourcis Windows (Menu Démarrer + Bureau)

PRÉREQUIS SUR PC DE CAISSE:
  ✅ Windows 10/11
  ✅ ~300-400 MB d'espace disque
  ❌ Java NON requis (inclus!)
  ❌ MySQL NON requis (SQLite embarqué!)
